# Редактор и runtime

Состояние контракта: 24.10.2026, исходный срез Сот `23b90658` и последующий UI-пакет обложек. Перед записью проверяй возможности текущего развёртывания. Наличие этой публичной инструкции не означает наличие MCP-операции у конкретного агента.

## Через интерфейс

Владелец приложения открывает действия соты → редактор обложки → «Выбрать картинку». Редактор принимает PNG/JPEG/WebP, показывает настоящий hex, малый размер, кадрирование и историю. «Сохранить» принимает выбор; отмена не меняет текущую версию. «Стандартная обложка» возвращает общий арт, «Без обложки» скрывает его. Название остаётся HTML-текстом.

Если агент управляет браузером по поручению владельца, используй этот готовый путь. Не вводи личные фото или закрытые файлы без выбора пользователя для этой задачи. Исходник уменьшается на устройстве, сырой файл не нужно передавать через модель. Генерация внутри редактора пока не подключена; выбранное изображение можно создать доступным инструментом агента и затем загрузить.

## Через существующий подписанный SDK

При наличии разрешённого `WorldApi` используй `createCoverApi` из `src/world/cover-api.mjs` и ту же логику редактора. Это внутренний подписанный UI adapter, не открытый анонимный HTTP API и не автоматически доступный внешнему MCP набор.

Для приложения действуют `apps.cover.status/prepare/prepareFromVersion/commit/read/versions/restore/remove/cancel`. Actor проверяется Connect; `appId` не заменяет текущую авторизацию. `status` возвращает текущую revision, scope и serverTime. Сохраняй точный `requestId` вида `cover1.<serverTime>.<32 lowercase hex>` до отправки; неизвестный сетевой результат проверяется через `status` с тем же ID, а не повторяется новой записью.

`prepare` принимает выбранный нормализованный raster и текущие `expectedTargetRevision`, `expectedPolicyEpoch`, `expectedCoverRevision`; подготовка не переключает обложку. Максимум входа — 320 KiB и 1 048 576 decoded pixels. `commit` принимает точные `requestId` и `draftId`, повторно проверяет владельца и scope. Для crop-only правки служит `prepareFromVersion`; кадр уже запечён сервером в canonical bytes, не применяй его вторично.

`read` проверяет актуальный доступ; private bytes имеют no-store и не попадают в модель, публичный manifest или CDN. `versions` даёт до 20 безопасных записей с фактическим `restorable`. `restore` использует новую текущую CAS revision. `remove` различает `inherit` и `none`. Перезагрузка, переименование и смена темы не запускают генерацию.

Для профиля существует отдельная семья `world.profile.cover.*`; она не даёт права менять приложения. Не подменяй её публичным app-art каталогом. Вызовы источника, токены, серверные права и provider grants не следуют из прочтения skill.
