# Приёмка релизной копии: первый вход и пустые состояния

Проверена копия `soty-experience-release/соты`, сервер `http://localhost:5201`, Connect 0.1.2. Эта проверка дополняет визуальную матрицу `audit-visual-20260928.md`. CUA был недоступен сессии audit_visual; финальную браузерную приёмку и снимки выполняет root. Ни один вывод по коду ниже не выдаётся за новый скриншот.

## Подтверждённые HTTP-результаты

- `/health`: 200, `ok=true`; подключения моделей в чистой локальной конфигурации не настроены.
- `/`: 200, `Cache-Control: no-store`.
- `index-D9Jdh8l0.js`, `main-RN3cKob4.js`, `world-adapter-CkXaJwZT.js`, `world-adapter-DqsKbB1B.css`: 200; SHA-256 каждого ответа совпал с соответствующим файлом релизного `dist`.
- `manifest.webmanifest`: 200, `display=standalone`, `start_url=/?pwa=1`, три иконки.

Это проверка сборки до перечисленных ниже небольших правок. После них нужен финальный rebuild; старые имена файлов не являются идентификаторами итоговой публикации.

## Исправления по результату проверки

1. **Первый экран нового профиля.** Значение по умолчанию в `src/world/preferences.ts` изменено с `world` на `mine` в исходной и релизной копиях. Новый пользователь получает записки и подключения, а не пустой публичный каталог. Явные маршруты и корректно сохранённые предпочтения остаются приоритетными.
2. **Независимость панелей ресурсов.** `openResources('devices')` больше не вызывает `apps.list`; `openResources('apps')` не вызывает `apps.devices`. Ошибка ненужного раздела раньше скрывала целевую панель вместе с действием подключения. Обновляется только кеш запрошенного ресурса, поэтому параллельная загрузка главной не перезаписывается старым snapshot соседнего ресурса. Изменён только релизный `src/world/app.ts`; root уведомлён о синхронизации.
3. **Описание шахмат.** В релизном `src/world/product.ts` текст «С другом или компьютером» соответствует уже реализованному выбору режима.

## Проверка веток реализации

- Вызван реальный `loadPreferences` через Node: 12 вариантов прошли. Отсутствующие, старые, неверные, повреждённые и недоступные настройки возвращают `mine`; каждый из пяти допустимых сохранённых экранов сохраняется.
- Конструктор приложения задаёт hash только при его отсутствии; deep links не заменяются новым default.
- Пустая главная содержит создание записки, добавление связи, переход к проектам и поиск/создание сообщества. Фиктивные объекты не добавляются; нулевые счётчики появляются после успешных ответов, а ошибки имеют отдельные состояния.
- В пустом мире есть создание сообщества; у скрытого профиля — явный переход к настройке видимости. При поиске без результата предлагается сменить запрос.
- Контакты передают Connect `initialTab='people'`, управление устройствами и QR подключения — `initialTab='devices'`. Модуль 0.1.2 проверяет допустимые значения, сохраняет стандартный fallback `profile`.
- Адаптер темы Connect импортируется хостом и имеет большую специфичность, чем поздно загружаемый standalone CSS. Цвета оболочки семантические, подложка QR остаётся белой.
- Переход из библиотеки в шахматы выбирает инструмент через URL; chooser содержит компьютер, приглашение друга и существующие комнаты. Общая навигация инструмента ведёт на явные hash-маршруты World.

TypeScript проверен после изменений. HTTP-запросы направлялись только на локальную сборку; пользовательские данные, реальные приглашения и публичные сервисы не изменялись. Недоступность отдельного API в браузере не инъецировалась; изоляция загрузок проверена по веткам реализации.
