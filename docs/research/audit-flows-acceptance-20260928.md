## Последняя находка на скриншоте

При изменении ширины с desktop на mobile уже восстановленный длинный черновик сохранял прежнюю высоту поля; вторая строка могла оказаться частично обрезанной. Добавлен `ResizeObserver` ширины composer, который пересчитывает высоту без циклической реакции на изменение высоты, и отключается при выходе из чата. Поле получает `min-width:0`, кнопка отправки не сжимается. Изменение прошло typecheck; повторную визуальную проверку на последней release-сборке выполняет ведущий исполнитель. Скриншот `chat-draft-mobile390.png` документирует состояние до этого дополнительного исправления и не выдается за финальный визуальный результат.
