## Почему не один ползунок от чёрного до белого

При наивной интерполяции чёрного текста к белому и белого фона к чёрному оба цвета в середине становятся одинаковыми: 1:1. Это не устраняется красивой анимацией. Переключение переднего плана в некоторой точке создаёт скачок, а сохранение одного цвета текста не позволяет охватить оба крайних режима с необходимым контрастом.

Поэтому режим и яркость — два независимых выбора. Ползунок всегда в середине при первом открытии, как предложено пользователем; системный режим уважает уже сделанный человеком выбор устройства. Внутри светлой темы яркость меняет тёплую поверхность от приглушённой до почти белой. Внутри тёмной — от почти чёрной до мягкой тёмно-зелёной. Текст никогда не проходит через серую нечитаемую середину.

Это ограничение нашего дизайна ради читаемости, а не требование стандарта использовать именно такой UI.

## Контракты интеграции

`src/world/theme/theme.ts`:

- `applyThemePreferences(loadPreferences())` — до bootstrap/lazy импорта World.
- `createThemeController({ initial, onChange })` — live preview, media change, синхронизация вкладок и сохранение настроек.
- `createThemeControls(controller)` — `{ element, destroy }`; вставляется в отдельный диалог оформления.
- Новые предпочтения `themeMode: system|dark|light`, `themeBrightness: 0..100`. Старый ключ хранилища сохранён. Views дополнены `notes`, `library`.

`src/platform/pwa.ts`:

- `getPwaController()` — один контроллер на страницу; вызывается рано в entry, затем переиспользуется приложением.
- `get/subscribe`, `requestInstall`, `checkConnection`, `checkUpdate`, `applyUpdate`, `destroy`.
- `registerUpdateGuard(async () => { await notes.flush(); return !notes.hasUnsavedChanges() && !forms.hasUnsavedChanges(); })`.
- `watchFormEdits` следит за реальным вводом, а не сравнивает программно заполненную форму с пустым `defaultValue`. После подтверждённого доменного сохранения вызывается `markSaved`. Отсоединённые элементы освобождаются. Изменение непустого значения на пустое также защищено.
- Notes с собственным durable guard помечает корень `data-pwa-ignore`, чтобы не блокировать уже сохранённый локальный draft общим детектором формы.
- Статусы установки: unavailable/available/prompting/accepted/installed; обновления: idle/available/saving/activating/blocked/failed; связи: checking/online/offline/unreachable. Недоступность API не равна потере локальных данных.

В waiting SW каждый клиент отвечает через отдельный MessageChannel. Таймаут или старый клиент без обработчика оставляет версию ждать. Если пользователь ввёл новый текст после prepare, финальная проверка сохраняет страницу без reload; действие обновления можно повторить после сохранения. При первой установке controllerchange сам по себе страницу не перезагружает. Сохраняется текущий и один предыдущий кэш ресурсов. При закрытии всех вкладок браузер может штатно активировать waiting worker.

`launch_handler: focus-existing` сохраняет уже открытое окно и его незавершённую работу вместо повторной навигации. Это enhancement с ограниченной поддержкой; на него не опирается сохранность черновиков. [MDN launch_handler](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Manifest/Reference/launch_handler). Формат и безопасное поле maskable-иконок учтены отдельно. [MDN icons](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Manifest/Reference/icons).

Это проверка настоящего worker/controller протокола и независимого тестового хранилища черновика. ## Границы

- Офлайн доступны загруженная оболочка, настройки и локально сохранённые данные; серверные участники мира, удалённые устройства и приложения требуют подключения. SW не сохраняет подписанные ответы API.
- Квота/запрет локального хранилища может помешать durable save. Guard должен оставить обновление заблокированным, а UI сообщить о несохранённом состоянии.
- Яркость — тон поверхностей приложения, не настройка физической яркости экрана.
- Legacy-комнаты имеют собственную старую тёмную палитру. Автоматическая замена только её текстовых переменных на светлые World-токены небезопасна из-за старых фиксированных тёмных поверхностей. Новая палитра World не выдаётся за законченную миграцию всех legacy-инструментов.
