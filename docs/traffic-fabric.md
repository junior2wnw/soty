# Интернет через Соты

Link Traffic — независимая возможность коннектора. Она позволяет телефону или
другому устройству выходить в интернет через выбранный компьютер, в том числе
через активный на нём VPN. Эта возможность не зависит от AI-адаптера.

## Состав

- `scripts/agent-modules/traffic-core.mjs` управляет закреплённым Xray Core,
  проверяет SHA-256 и атомарно обновляет исполняемый файл.
- `server/traffic-control.js` выдаёт и отзывает клиентские ключи и хранит
  маршруты к выбранному выходу.
- `server/traffic-tunnel-proxy.js` связывает публичный HTTPS с изолированным
  шлюзом.
- `src/features/traffic-fabric.ts` содержит клиент API экрана настройки.
- `deploy/traffic/generate-gateway-config.mjs` создаёт постоянный пул выходов.

Все части включаются отдельно. Без `SOTY_TRAFFIC_*` серверный control plane не
активируется; без `trafficCoreEnabled` коннектор не запускает сетевое ядро.

## Транспорт и безопасность

- компьютер ↔ шлюз: VLESS + XHTTP/H2 + TLS/443;
- телефон ↔ шлюз: VLESS + WebSocket + TLS/443 как совместимый мобильный путь;
- неизвестный трафик шлюза отправляется в `blackhole`;
- каждому клиенту выдаётся отдельный UUID и отдельное правило;
- отозванный ключ удаляется из обоих входов и таблицы маршрутов;
- состояние control plane записывается атомарно с правами `0600`;
- при строгом VPN-режиме исчезновение выбранного интерфейса закрывает выход,
  а не переводит трафик на прямое соединение.

Сервер разрешает управление трафиком только для Link с живым коннектором.
Локальный экран дополнительно проверяет совпадение Device ID, поэтому чужой
коннектор на `127.0.0.1:49424` не может подменить выбранный компьютер.

## Проверка

```sh
pnpm run traffic:selftest
pnpm run traffic:smoke -- --agent http://127.0.0.1:49424
```

Для шлюза нужны `SOTY_TRAFFIC_TUNNEL_TARGET`,
`SOTY_TRAFFIC_TUNNEL_PATH`, `SOTY_TRAFFIC_WS_TARGET`,
`SOTY_TRAFFIC_WS_PATH` и `SOTY_TRAFFIC_XRAY_API`.
