# Историческая интеграция SpreadEx ML

Начиная с коннектора 1.4.15 встроенный SpreadEx ML runtime и его локальные
маршруты отсутствуют. После обновления коннектора эта ML-функция перестанет
работать, а приложение может потерять связанное подключение. Запущенный старый
коннектор изменится только после отдельного выпуска и обновления.

Сохранённое поле `spreadexMl` передаётся через `connector-config.json` без
изменения. Новая версия не читает и не удаляет прежние файлы секретов и runtime
SpreadEx. Предыдущие исходники, публичная сборка и manifest доступны в Git на
`43e97420b8f24496af6eaff1bd3160df10bad933`; фактический откат должен учитывать
состояние конкретного установленного коннектора и данных.
