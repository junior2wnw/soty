# Компактные действия основного окна приложения

Длинный статус и ряд кнопок занимали большую часть низкого экрана. Теперь
настоящее сообщение остаётся в компактной строке с одной кнопкой действий.
Полный текст, повторный запуск, новая вкладка и скрытие доступны в обычном
диалоге Сот. Доступность исходных действий и проверки текущего открытия
сохранены. Изменение размера и открытие диалога не перемещают iframe.

67 проверок main/widget, scoped launch, runtime phase, metadata и refresh
прошли; TypeScript и Vite завершились успешно. В Chrome с полным CSS
кандидата проверены 320×540, 390×320, 768×540 и 1440×900: строка статуса
занимает 56 px; видимые действия диалога имеют высоту не менее 44 px.
Tab/Escape и скрытие возвращают фокус к доступному элементу. Счётчик,
черновик и тот же iframe сохранились после диалогов, resize и fullscreen.
Явные retry и external дали по одному соответствующему запуску.

Это компонентная проверка с публичными искусственными данными. Причина
пустого HIVE, физический touch и screen reader не приняты. Эти изменения
ещё не опубликованы; рабочий сервер остаётся на ревизии 83b7d1b.
