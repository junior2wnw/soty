## Исправленные причины

- Поздний ответ сервера больше не возвращает старую прокрутку и не крадёт фокус у поиска.
- Escape во время IME не закрывает поиск; собственная отправка сохраняет позицию читающего историю.
- Права самостоятельного группового чата обновляются с сервера; архив и отзыв доступа закрывают устаревший transcript.
- Контекстное меню не исчезает от запоздалого события scroll.
- Обсуждение приложения ограничено высотой рабочей области; мобильная переписка получает экран, composer не пересекается с навигацией.
- Повторная загрузка неизменившихся grant metadata не перезапускает обсуждение.
- «Мои проекты» доступно на телефоне; фильтры переносятся без горизонтального переполнения.
- Переключение карточки/поле и закрытие действий возвращают фокус в существующий элемент.
- В помощнике сохранён account fence, удалены лишние поля строгих SDK payload, допускается только корректный ещё не leased queued receipt; новая форма остаётся под тем же guard.
- Пайплайн обложек отклоняет повреждённые и несогласованные import/edit/rollback до изменения указателя, сохраняет crop и provenance.
- Content-hashed WebP получает immutable cache, manifest перепроверяется. Private prompts/jobs/history не попадают в HTTP/Git/Docker.
- Полный Docker build получает настоящие deploy/apps тесты, ранее исключённые из build context.
