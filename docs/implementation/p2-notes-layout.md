# P2 — записки и неподвижная оболочка на низком экране

2026-09-30. Локальный browser gate; production не менялся.

## Найденные причины и исправление

1. На 844×390 боковая rail переполняла высоту. Фокус текста прокручивал скрытый scroll container `#app` на28px: верхняя панель уходила за край. Корневая grid-оболочка теперь `overflow:clip`, rail имеет собственную прокрутку и не сжимает controls. В коротком окне уменьшаются промежутки; при844×390 профиль целиком виден y342..386, rail clientHeight=scrollHeight390. Это не обработчик, насильно возвращающий scrollTop.
2. На667×375 sticky toolbar записки перекрывал первую строку textarea после клавиатурного фокуса. Панель и отдельная прокручиваемая область теперь соседние flex-элементы. Высота панели определяется содержимым, координаты её нижнего края не дублируются в JavaScript/CSS offsets.
3. Прежнее раскрывающееся меню обрезало нижнее действие коротким редактором. Действия открываются через общий native dialog: фон inert, Escape закрывает, фокус возвращается к кнопке. Сохранены цвет, архив, корзина, восстановление, подтверждение окончательного удаления и скачивание. Меню читает актуальное состояние при открытии, закрывается при rerender/dispose. Старый details CSS удалён.
4. `box-sizing:border-box` задан самим оболочке и dialog, а не только их детям: mobile sheet больше не занимает669px в667px viewport.

Различие `hidden` (допускает программную прокрутку) и `clip` (не создаёт scroll container) проверено по [MDN overflow](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/overflow). Внутренние содержательные области сохраняют `overflow:auto`; одна замена clipping без доступной внутренней прокрутки не считалась решением.

## Проверено реальным браузером

- IAB, локальный dev5410, настоящая синтетическая записка с названием, текстом и checklist. Не страница-макет.
- 844×390: фокус title/body/checklist, Shift+Tab, профиль через клавиатуру. Header top0, shell scrollTop0. После уплотнения profile целиком виден без скролла.
- 667×375: textarea y143..293 ниже toolbar bottom125, scroll viewport y125..311, нижняя навигация y311..375. Меню width667, последняя кнопка y310..354; все действия доступны.
- Архивирование → подтверждение «Сохранено» → восстановление → «Сохранено»; содержимое и checklist остались прежними.
- 320×760: reload возвращает название, текст, checklist и «Сохранено»; меню, Escape и возврат к списку работают, фокус возвращается на opener/search. Editor скрыт при показе списка; горизонтального переполнения нет.
