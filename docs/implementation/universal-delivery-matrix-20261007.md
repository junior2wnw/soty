# Приёмка единой системы Сот

Это рабочая карта результата по запросу пользователя. Она различает созданный код, проверенный сценарий и включённую работу на сервере. Общая программа ещё не завершена; действующие приложения не обновлялись в этом проходе. Свидетельства привязаны к точным версиям, а наборы тестов разных уровней не заменяют друг друга.

Первый законченный межприложенческий сценарий должен соединить HIVE, Планировщик и Переметрику: один человек, отдельные текущие Source права, чтение разрешённых данных, два согласованных изменения, видимый результат и обращение к нужному владельцу проекта. TRANSIT подключается через разрешённый локальный контекст и обзор статуса; живые экспериментальные узлы не разрешают продажи, выплаты или изменение финансовой защиты. Тавыш сохраняет прежние local-first данные и воспроизведение. Другие приложения используют те же уровни допуска, без специальных прав по своему названию.

Пилот selected-project фиксирует один проект. Для дальнейшего роста Source должен сам владеть навигацией по разрешённой библиотеке/коллекции и выдавать ограниченные текущие квитанции выбранного проекта. Root хранит указатель и версию approved adapter, не копию Native ACL. Настройка64 профилей,100 приложений на аккаунт и256 активных слотов — пределы текущего пилота, не доказательство готовности обслуживать любое число авторов. Новый Source kind не должен требовать очередного формата Root БД.

Самостоятельное подключение автора принимается только после проверки владения Source и явного Native согласия там, где оно нужно. Пользователь получает короткие действия; issuer, digest, MCP transport и ключи остаются в технической части. Статус готовности отражает реальную проверку входа, проекта и очереди, а не наличие manifest. При неизвестном ответе сохраняется прежний запрос; результат проверяется отдельно, повторного эффекта по новому ключу нет.

Подготовленный код не является публикацией. Перед выпуском нужен конкретный совместимый комплект Root+Source, current config witness, сохранённые данные, Source browser/ACL tests, ограниченный запуск и проверяемый откат.
