Изменения интерфейса не потребовались. Скриншоты перечисленных состояний просмотрены в инструменте; отдельные PNG этого прохода не сохранялись. Геометрия и фокус дополнительно измерены read-only DOM API, не оценены по уменьшенному превью. В начале browser automation селектор `role=checkbox` для «Архив» не совпал с фактическим DOM button/aria-pressed; после свежего DOM snapshot использован настоящий button. Это ошибка тестового селектора, не продуктовый дефект.

## Проверка хранилища после UI

Отдельный read-only `var/p4-native-browser/audit-landscape.mjs` выполнил assertions на настоящих SQLite файлах: одна active Note с revision4, один native proof, один Invocation, одна receipt, input purged; проверенная строка budget имеет reserved0/spent1. Скрипт подтверждает эти текущие количества, но не сравнивает прежние ID/digest/proof и не связывает выбранную строку budget с Invocation. Прежняя revision2 документирована в предыдущем browser proof; точный текст и открытие того же Note ID проверены через отрисованный editor после reload/update. SQL-аудит не извлекает содержимое или credentials и сам по себе не доказывает неизменность предыдущей квитанции.

Независимый reviewer прочитал документ и SQL-проверку без нового запуска. Его замечание о слишком сильном выводе по count/первой строке budget учтено этим уточнением; browser evidence остаётся наблюдением root, не независимым повтором.

Временный override viewport сброшен. Вкладка оставлена на прежней записке. Главная возвращена к карточкам, тестовый Assistant draft пуст.
