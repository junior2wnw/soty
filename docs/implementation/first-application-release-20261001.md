C на этой отдельной восстановленной копии прошёл readiness до допуска к исходному тому.
- C запущен один раз в13:32:02.877 UTC; последующее завершение переключения и wiring его не перезапускали. O остался остановленным с `restart=no`, неизменным StartedAt; старый несовместимый код не возвращался на новые данные. У C восстановлена `unless-stopped`.
- Journal завершён без pending transaction. Сохранены backup, predecessor и module sequence2. Выделенный buildx builder удалён; рабочий контейнер не затронут.

Во время выпуска обнаружены три конкретные ошибки: сокращённый Docker mount summary ошибочно считался общим томом; холодный WAL SQLite не мог читать sidecars на RO filesystem; running format probe стартовал до завершения миграции. Исправлены полным штатным Docker inspect, ограниченной копией только холодного main/WAL/SHM в tmpfs и ожиданием readiness перед running probe. Исходное хранилище при cold probe остаётся RO; WAL не игнорируется, `immutable` не применяется; для работающего writer копирование отключено. Завершившиеся неуспешные helpers сохранены как отказы, а не превращены в успешные receipts. Повторного C START не было.

До переключения выпуск занял больше запрошенного часа; cold pause привёл к временной недоступности сайта. Ошибки выпуска и реальные RED не скрываются. ## Граница результата

Первый человеческий production выпуск принят; весь master-план не объявляется завершённым. Public discovery опубликован без авторизации, но `/api/capabilities/v1/status` честно сообщает `notesCreateEnabled:false,audience:null`. Совместимость каждого ИИ-клиента не проверялась. Новые AS/native внешние допуски по умолчанию закрыты. Реальные платные модельные вызовы не выполнялись.

Остаются внешний пилот именных приложений с настоящими проектами/автором/посетителем, полная HTTPS-проверка двух внешних AI-клиентов с отзывом доступа, физический телефон/установка PWA и новые независимые runtime/SDK/hosting/community гарантии P5–P7. Существующие помощник, connector и функции не выдаются за выполнение этих будущих гарантий. Первый Windows guard RED и его отдельная незапущенная диагностика сохранены; они не используются как доказательство этого выпуска.
