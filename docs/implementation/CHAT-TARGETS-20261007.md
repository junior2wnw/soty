# Области нажатия в чате

07.10.2026. Source-кандидат; production пока не обновлён этой правкой.

На фактическом экране шириной320 CSS px меню сообщения имело область30×44px, а переход к последним сообщениям38×38px. В горизонтальном режиме844×390 кнопки шапки/поиска и отправки были36–38px. Иконки и текст оставлены прежними; области этих действий, отмены ответа и перехода вниз увеличены до44×44px для узкого экрана, coarse pointer и короткого окна до1100px. Сетка поиска в горизонтальном режиме учитывает ширину кнопок. Backend, сообщения, права и отправка не менялись.

Размер44×44 выбран для этих controls как усиленный ориентир удобства, согласно [W3C Target Size Enhanced](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced). Минимальный AA-ориентир24px отличается; исходные30px сами по себе не объявляются нарушением этого критерия. Изменение нескольких controls не означает полное соответствие сайта WCAG.

Fixture показывает состояние отсутствия серверной связи; это не проверка реального offline transport.
