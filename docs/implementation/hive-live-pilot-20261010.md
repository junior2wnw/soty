# Действующий пилот HIVE — 10.10.2026

Поручение: настоящий вход двух профилей → обращение → черновик агента → ответ владельца. Телефон в текущем этапе проверяем размерами браузера 320/390 по ответу пользователя; это не проверка физического телефона.

Используем существующее приложение `app-3b8909dc3fdfb07ee8d427fecde1b68a` и адрес `https://hive.4-2.xn--p1ai`. Прежний Pocket ID, callback, browser origin и данные сохраняются. Старый проект не используется как тестовый объект.

Для первой законченной цепочки владелец сам передаёт ограниченный текст обращения в существующий Помощник Сот. Он получает подтверждённый ответ `agent.turn`, нажимает «Сохранить в Записки», проверяет читаемую записку после перезагрузки, затем редактирует и отправляет ответ через обычный Native HIVE `reply`. Отправка имеет свежие account/ACL/revision проверки. Скопированный текст не даёт агенту HIVE-права. Вложения и автоматическая ASR/OCR не включены в этот первый текстовый сценарий.

Черновик использует существующие Notes Session/CAS/outbox, без новой очереди, таблицы черновиков или обхода processing consent. Unknown сохраняет прежний Notes mutation; повторная проверка не вызывает модель. Подтверждённые диалоги агента уже отдельно хранятся в Notes.

HIVE UI кандидат: `25d30e8a779b245749d762de5cf286a28a3519d4`, база `3a66756cc5208f97efb2401ed53eda903757ca06`. Три изменения: отдельный reply каждого ticket, защита выбора от позднего read, проверки границ. 38 целевых проверок, типизация и обычная Vinext сборка прошли у соседнего чата. Одиннадцать незавершённых processing изменений из другого worktree в этот кандидат не включены.

Root readable-draft: 19 целевых проверок с настоящим Notes SQLite и строгая целевая типизация прошли. Полную проверку обеспечивает стандартная закреплённая Docker сборка; целевые проверки не заменяют её.

На Dev до обновления Root `ec50df7` и HIVE `ca47fc3`: новый Human Identity, personalAgent и HIVE feedback выключены. Их отсутствие не маскируем формой или учебным пользователем. В настоящем commerce каталоге найден `zai-org/GLM-5.3-Flash`; это наличие маршрута, не подтверждение генерации или оплаты. Model requests = 0 на момент подготовки.

Перед изменением действующей базы: зашифрованная согласованная SQLite копия и конфигурация, восстановление из неё в изолированной среде, проверка старых таблиц/ACL после миграции, совместимый возврат. Публикация и успешный весь сценарий отмечаются отдельно по фактическим проверкам. Все R01–R22 остаются в общей матрице; этот пилот не закрывает всю платформу.
