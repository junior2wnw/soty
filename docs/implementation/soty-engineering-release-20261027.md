## Что изменилось

- Основные переходы собраны вокруг «Моё», сообщений и поиска. Приложение и его
  обсуждение используют общий контекст; черновики разделены по аккаунтам и
  разговорам, восстановление учитывает одновременную работу вкладок.
- Подготовленное совместимое приложение подключается через общий коннектор и
  стандартный модуль входа. Предметные данные разделяются по подтверждённому
  человеку. Первая авторизация устройства и новые полномочия остаются явными.
  Существующий сторонний сайт требует совместимого адаптера.
- Приложения владельца доступны и при отсутствии ярлыка на текущем поле.
  Кнопки поля и этот список объединены в плавающую группу; поле сохраняет
  размер и камеру. Клавиатурный фокус прокручивается в видимую область.
- Плавающий помощник сначала избегает всех объектов. При нехватке места
  доступ к QR, навигации, формам и iframe важнее свободной перемещаемой
  карточки. Сохранённая пользователем позиция не переписывается.
- Закрытый запрос коннектора больше не забирает задание после отмены, в том
  числе при ожидании очереди записи. Уже совершённая запись не отменяется
  задним числом. Ошибка stdin завершает выполнение с ошибкой без слепого повтора.
- Исходный архив сверяется с Git по всем файлам и режимам. Контрольные суммы
  Windows-пакетов соответствуют каноническим LF-байтам на всех checkout.

## Применение и границы

[Размещение приложений](../../skills/soty-app-deploy/SKILL.md) описывает обычный
путь и восстановление. [Концепция рабочего пространства](../research/soty-workspace-20261027/README.md)
содержит презентацию и интерактивный пример; это целевая модель продукта.

Общий релиз для всех людей и устройств ещё не квалифицирован: остаются реальные
пользователи, физические устройства, доступность и измеренная нагрузка. SDK
остаётся preview; произвольный сторонний код не объявляется изолированным
универсальным runtime. Сохранена необходимая совместимость старых приложений.
Открытое приложение в другой вкладке может остановить общую активацию PWA,
чтобы не потерять его несохранённое состояние.
