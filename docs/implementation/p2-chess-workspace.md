# P2 follow-up — единое пространство шахмат

2026-09-30. Исходная контрольная точка `60bd426`. Локальная реализация и независимая проверка завершены; это не подтверждение полной внешней P2-матрицы и не публичная выкладка.

## Исправление

Standalone-доска на 1024×768 обрезалась окружающими инструментами комнаты. При независимой проверке входа из обычной комнаты обнаружена другая ошибка: на 320px мобильная панель статистики сжимала доску до 20.84px. Теперь любой вход в шахматы открывает один игровой workspace; отдельной компактной overlay-раскладки нет.

Доска вписана в квадрат по двум фактическим размерам её контейнера (`min(100cqi,100cqb,560px)`). На телефоне статистика расположена под доской, на широком экране — рядом. Панель комнаты и технические действия устройства не занимают место игры. Чат партии — другой вид той же комнаты, не новый разговор. Возврат из входа комнаты использует фиксированный `chess-back` enum и не перезагружает страницу. Текущий tunnel, черновик и ответ на сообщение сохраняются.

Клавиатура имеет одну точку Tab на доске; стрелки выбирают поле, Enter/Space используют обычное действие кнопки. При перерисовке фокус внутри доски сохраняется; во время хода компьютера он остаётся на доске, а фокус, уже перенесённый в чат, не перехватывается. Подписи статистики и выбора фигуры русские; «Рекорд» явно обозначает длину завершённой партии в полуходах. При восстановлении сохранённой партии не добавляется повторное приветствие; старые сообщения не удаляются.
