# Публичные приложения на каждом полотне

Главное полотно показывает объединение собственных зарегистрированных и общедоступных приложений. Прежний отбор `ownerAccountId === currentAccountId` исключал публичные приложения другого владельца, хотя общий поиск и ссылка уже работали.

`refreshLiveApps` получает собственный список и общий каталог независимо, объединяет ID и разрешает их обычным `apps.directory.resolve` пакетами не более60. В слой попадает только актуальная разрешённая проекция. Сырые сведения каталога не дают доступа, не заменяют адрес и не открывают приложение. Ошибка одного источника не скрывает другой; частичная загрузка явно сообщается.

Слой доступности не записывает приложения в личную раскладку: собственные позиции, виджеты, группы, история и камера сохраняются. Уже представленное приложение не дублируется. Первый доступный набор на пустом полотне кадрируется один раз; ручная камера и следующие обновления не сбрасываются. Общие приложения находятся и в поиске своего полотна. Отзыв публикации убирает автоматические соты и строки поиска у остальных пользователей; собственное приложение остаётся доступным владельцу.

Публичность приложения не предоставляет право управления или доступ к чужим записям. Само приложение и его API сохраняют собственные вход и роли. Для публикации ранее закрытого приложения применяется штатная подписанная owner-операция с актуальным target/CAS и подтверждением раскрытия. Публичный `entryPath` не защищает остальные маршруты порта; служебные редакторы нельзя раскрывать без проверенной защиты API.

Изменение использует существующие `apps.list`, `apps.catalog` и `apps.directory.resolve`, не меняет backend, схему данных или серверные права. UI публикуется отдельно штатным `deploy/ui/host-publisher.mjs` с сохранением прежних immutable URLs. Проверки публичного браузера и конкретной публикации фиксируются отдельно от тестов модели.

Регрессии: `unified-field-app-coverage.test.mjs` проверяет владельца/другой аккаунт, частичные отказы, одно первое кадрирование, отзыв и сохранность; `unified-field-mine-ownership.test.mjs` сохраняет100 собственных плюс60 публичных приложений и предел пакетов; `unified-field-search-results.test.mjs` проверяет открытие общего приложения из поиска и запрет устаревшей строки после отзыва. Те же новые критерии проваливаются на прежнем отборе владельца.
