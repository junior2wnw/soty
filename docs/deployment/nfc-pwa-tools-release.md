Web NFC не раскрывает модель чипа, технологию, размер полной памяти и статус защиты. Низкоуровневые команды и эмуляция карт не входят в API. UID не превращается в предположительный IC type. Байты из API — декодированные данные записи, а не дамп памяти или полный радиопакет. Отчёты из файлов не считаются живым чтением; аппаратные заявления в них не принимаются.
