Добавляются: NDEF-диагностика, раздельная проверка формата URI и неизвестной совместимости чипа, отчёты с явным выбором содержимого/идентификаторов, импорт отчётов с отметкой источника, непрерывное чтение с остановкой при hidden, история последних десяти чтений в памяти, ручная серия записей с проверкой и счётчиками, файлы MIME, скачивание данных API, Android AAR, Smart Poster и внешние типы NDEF. Координаты новых геометок записываются как HTTPS-карта; прежние raw geo-снимки сохраняются.

Web NFC не раскрывает модель чипа, технологию, размер полной памяти и статус защиты. Низкоуровневые команды и эмуляция карт не входят в API. UID не превращается в предположительный IC type. Байты из API — декодированные данные записи, а не дамп памяти или полный радиопакет. Отчёты из файлов не считаются живым чтением; аппаратные заявления в них не принимаются. Совместимость конкретных меток с iPhone 14/15/17 ещё не установлена.

Локальные проверки завершены: 43 теста / 0 ошибок, production build Vite, проверка синтаксиса и git diff --check. В настоящем браузере проверены импорт полного и обезличенного отчётов, экспорт без payload/ID, Wi-Fi с закрытым паролем, скачивание байтов, копирование, подготовка URI из текста с подтверждением, импорт двоичного файла, подготовка/завершение серии и сохранение черновика после reload. Прежний проверочный черновик экспортирован перед QA и восстановлен через штатный импорт. На ширинах 320, 390 и 768 px горизонтального переполнения нет; фон не прокручивается за открытым диалогом. Скриншоты находятся в локальном output/nfc, данные из файла явно отмечены.

Отдельно исправлено реальное поведение NDEFRecord.toRecords(): MIME, unknown и локальные типы не передаются этому методу; внешний тип может содержать произвольные байты, поэтому ошибка вложенного разбора не уничтожает читаемый payload. Есть тесты отказа метода для MIME/AAR, локальных записей Smart Poster, UTF-16 и суммарных лимитов чтения. NFC-события в браузер QA не подменялись.

Текущие настройки сверены через SSH чтением registry.sqlite с readOnly/query_only в одном snapshot. Экспортированы только поля soty.app-deployment.v1; owner/grants/connector credentials не выгружались, неизменность связей проверяется локальным SHA-256. Это операторская read-only проверка, не подписанный вызов apps.inspect. Порт 5318, путь /, source revision 1 / digest f100516d36fd17fdb2bff417150535b7be15f104dfa584f030bb53cf06bb7bb7, policy epoch 2, anyone/listed и активный прежний domain ID подтверждены. Источник-коннектор не меняется, prepare/promote и изменение публикации не требуются.

Перед публикацией остаются: immutable image из одного Git revision; Linux-тесты, кандидат и совместимый откат; обновление только NFC-сервиса и его исходников; публичные HTTP/TLS и браузерный вход. Секреты, том платформы, source/app/domain IDs и аудиторию сохранять.
