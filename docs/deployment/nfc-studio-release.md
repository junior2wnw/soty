Платформа 66ea740e0f23aa5c4788a5f74d52db15911e2d51 прошла полный Docker build и предусмотренные им проверки. Вторая ошибка привела к временной недоступности Сот. Совместимый контейнер восстановлен после свежей проверки всех четырёх форматов, без смены маркеров или удаления данных.

Исправления: точный Docker inspect для пропущенного Source; холодная проверка на ограниченной RAM-копии с сохранённым WAL. Проверены холодный main1/WAL2, неизвестный формат в WAL, лимит размера, orphan journal и симлинки. Linux Node 24: все 5 новых проверок проходят. Это проверка форматов, не доказательство полного backup/restore.
