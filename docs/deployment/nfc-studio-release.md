## Интерфейс и границы проверки

Реальные браузерные проверки: выбор типа, URL и Wi-Fi, скрытый пароль, сохранение шаблона, импорт файла и QR-шаблона с подтверждением, восстановление кириллицы. QR всегда использует публичный NFC origin; фрагмент с данными добавляется только по выбору пользователя. Измерены ширины 320, 390 и 768: горизонтальной прокрутки нет. Основное действие — 56–60 px, нижние кнопки — 50 px; области нажатия памяти и справки увеличены до 44 px. Снимки сохранены в output/nfc этой рабочей копии.

Окончательный вход внутри Сот — одна кнопка «Открыть NFC». Тип и содержимое вводятся после перехода, собственная нижняя навигация во встроенном входе убрана. Существующие встроенные черновики сохранены и могут быть выгружены из меню. Проверен публичный вход на ширине 320: основное действие 284×56 px видно целиком без прокрутки iframe. Кнопка открыла отдельную вкладку с правильным origin; в ней появилось описанное ниже защитное предупреждение. Черновик вводится уже в отдельном приложении, поэтому его не нужно переносить из встроенного браузерного контекста.

У приложения есть PWA-манифест; gateway запрещает workers. Service worker не зарегистрирован. Проверена загрузка манифеста, но не установка PWA на физическом телефоне и не новое открытие без сети. Уже загруженный интерфейс не отправляет содержимое NFC на сервер.

В управляемых Chrome и in-app browser отдельное открытие этого домена остановлено браузерным предупреждением «Осторожно, поддельный сайт!». Встроенное открытие в Сотах работает. CSP и защита браузера не ослаблялись, предупреждение не проходилось автоматически. Влияние на обычный Chrome Android ещё не подтверждено; пользователь получил запрос проверить адрес на телефоне. Для Web NFC требуется верхнее окно, поэтому это ограничение нельзя считать проверенной готовностью аппаратной записи.

Аппаратное чтение/запись не проверены: Windows-компьютер не имеет NFC. Поддерживаемый сценарий — Android Chrome с NFC и доступными для записи NDEF-метками, например NTAG213/215/216. Запись любого произвольного NFC-чипа, защищённых пропусков, платёжных карт и NFC из браузера iPhone не обещается. Проверять на телефоне: открыть отдельное приложение → выбрать тип и заполнить → «Записать» → поднести метку и дождаться повторного чтения. Состояния «записано» и «записано и проверено» различаются.
