# Соты: единая геометрия и глубина PWA

Основание: замечания владельца к сплющенным сотам, переполнению, плоской структуре, незаметным запискам, теме и готовности к росту. Сохраняем предыдущую рабочую реализацию. Работа ведётся тремя специалистами и root; рабочий сервер и личные данные не используются для экспериментов.

## Порядок реализации и приёмки

1. **Геометрия.** Одна модель правильного flat-top шестиугольника: `W=2R`, `H=√3R`; положения из axial-координат, равномерный зазор, внутренний безопасный прямоугольник. Размер задаётся одной величиной, высота не назначается отдельно. Миграция нового и прежнего интерфейса, аватаров, логотипов и загрузки. Математические тесты + измерение настоящих элементов.
2. **Рабочее пространство.** Постоянно видимые записки и библиотека возможностей, компактная главная с настоящими устройствами/приложениями/группами, быстрый возврат, контекстные действия. Минимум текста — короткие различимые подписи, не загадочные иконки.
3. **Записки.** Личные записи и списки с подтверждённым сохранением, поиском, закреплением, восстановлением и защитой от конфликтов. Прежние совместные тексты сохраняют свою модель доступа и явный вход; молчаливого переноса нет.
4. **Тема и PWA.** Светлая/тёмная/системная палитра и плавная настройка её яркости с серединой 50. Контраст проверяется по диапазону. Установка, обновление, состояние связи и сохранённые черновики отражают действительность; обновление не прерывает ввод.
5. **Рост и устойчивость.** Поиск через индекс, последовательная пагинация, честные ограниченные счётчики, ограниченный DOM и очистка подписок. Нагрузочные измерения отделены от обещания обслуживания миллионов людей.
6. **Приёмка.** Ширины 320/390/768/1440, светлая/тёмная темы и крайние положения настройки, длинные строки, клавиатура, Back/reload, записки между вкладками/без сети, все существующие функции, сборка и регрессия. Настоящие снимки и измерения сохраняются в отдельный каталог.

## Реестр проверяемых идей

Каждая идея получает основание, решение и проверку. Один прочитанный первоисточник может обосновывать несколько решений; отдельный поисковый запрос не считается исследованием. Подробности геометрии, записок и темы описываются в соответствующих отчётах исследований.

| ID | Идея | Критерий результата |
| --- | --- | --- |
| H1 | Одна формула шести сторон | Равные длины сторон на всех размерах |
| H2 | Одна независимая величина размера | CSS/inline не растягивают высоту отдельно |

| H4 | Безопасная область содержимого | Длинные имена/изображения не выходят за грань |
| H5 | Рамка как геометрический inset | Толщина не деформирует внутреннюю соту |
| H6 | Общий контур группы из её ячеек | Нет произвольной оболочки, пересекающей дочерние соты |
| H7 | Одна модель для старого и нового UI | Старые комнаты не сохраняют неверные шаги |
| H8 | Регрессионные инварианты | Тесты размеров/сторон/зазоров и DOM-измерения |

| U3 | Избранные возможности | Выбор привязан к текущему аккаунту |
| U4 | Компактная рабочая главная | Полезные действия вместо пустого рекламного блока |
| U5 | Продолжение недавней работы | Ссылка повторно проверяет доступ на сервере |
| U6 | Быстрая записка с главной | Не нужно искать функцию в прежних комнатах |
| U7 | Поиск действий с клавиатуры | Ctrl/Cmd+K, стрелки/Enter/Escape и видимый вход |
| U8 | Значки с короткими названиями | Основные назначения понятны без наведения |
| U9 | Короткий отклик на действие | Подтверждение успеха соответствует серверу |
| U10 | Индексированный каталог | Нет полного `instr`-сканирования на каждый ввод |
| U11 | Пагинация без OFFSET | Изменение предыдущей страницы не пропускает следующий результат |
| U12 | Честные границы масштаба | Ограниченные выборки/счётчики; измерения, а не обещания миллиардов |
| N1 | Явное место записок | Видимая вкладка и карточка на главной |
| N2 | Текст и чеклист в одной записи | Один понятный редактор без лишней разметки |
| N3 | Автосохранение с настоящим статусом | «На устройстве» отличается от серверного «Сохранено» |
| N4 | Черновик переживает закрытие | Данные разделены по аккаунтам и вкладкам |
| N5 | Конфликт не уничтожает текст | CAS, актуальная версия и сохранение копии |
| N6 | Поиск/закрепление/архив | Ограниченная выдача и быстрый возврат |
| N7 | Корзина и восстановление | Ошибочное удаление обратимо |
| N8 | Совместимость со старыми текстами | Явный вход без смешения разных прав доступа |
| T1 | Светлая/тёмная/системная тема | Учитывается системный выбор |
| T2 | Плавная настройка, середина 50 | Нет промежуточной нечитаемой палитры |
| T3 | Семантические цветовые токены | Диалоги, сообщения и новые модули используют ту же тему |
| T4 | Проверенный контраст | Основной/вторичный текст, границы, фокус |
| T5 | Тема до первого кадра | Нет светлой вспышки перед тёмным экраном |
| T6 | Установка PWA по действию | Предлагается только поддерживаемый способ |
| T7 | Безопасное обновление PWA | Не теряются несохранённые изменения |
| T8 | Честное отсутствие сети | Оболочка открывается, серверные действия не притворяются успешными |

## Исследовательские основания root

- [NN/g: progressive disclosure](https://www.nngroup.com/articles/progressive-disclosure/) — U2/U4: часто нужное на первом уровне, расширенное через явную библиотеку; не прятать существование функций.
- [NN/g: recognition and recall](https://www.nngroup.com/articles/recognition-and-recall/) — U1/U3/U5/U6: постоянные ориентиры и видимое продолжение работы снижают необходимость помнить путь.
- [NN/g: icon usability](https://www.nngroup.com/articles/icon-usability/) — U8: оставляем короткие подписи у неоднозначных значков.
- [Material: navigation bar](https://github.com/material-components/material-components-android/blob/master/docs/components/BottomNavigation.md) — U1: пять основных назначений помещаются в нижнюю навигацию; профиль остаётся в шапке.
- [W3C: combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) — U7: поиск действий должен иметь полноценный клавиатурный контракт, а не один глобальный обработчик.
- [W3C: status messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html) — U9: действия имеют доступный статус без постоянного перехвата фокуса.
- [W3C: reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) — плотность не отменяет перенос и доступность управления при 320 px.
- [web.dev: DOM size](https://web.dev/articles/dom-size-and-interactivity) и [INP](https://web.dev/articles/optimize-inp) — U4/U9/U12: ограниченный DOM, короткая работа обработчиков, замеры вместо обещаний.
- [SQLite: FTS5](https://www.sqlite.org/fts5.html), [query planner](https://www.sqlite.org/queryplanner.html), [EXPLAIN QUERY PLAN](https://www.sqlite.org/eqp.html) — U10/U11/U12: индексированный поиск, диапазон вместо OFFSET, проверка планов запросов.

Эти источники дают основания для решений; они не доказывают рост возвращаемости именно Сот. Это проверяется отдельными пользовательскими наблюдениями и метриками после рабочего запуска.
