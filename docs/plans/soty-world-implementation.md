# Соты — план реализации общего мира

Старт: 28 сентября 2026. Основание: утверждённые пять пар экранов в `output/soty-common-world-20260927` и уточнения владельца продукта. Реализация — живые DOM/SVG/CSS-компоненты, без подмены интерфейса картинками.

Идея: общее пространство людей и сообществ, в котором каждый собирает свою сеть устройств и приложений, находит других, общается и создаёт с ними новые возможности при помощи ИИ, сам выбирая, что открыть миру.

## Порядок и правила сдачи

Независимые модули готовятся параллельно тремя специалистами; интеграция и приёмка проходят в порядке 1 → 2 → 3 → 4 → 5. Завершённым считается проверенный пользовательский сценарий с работающим сервером, а не наличие кнопки или одного API. Выпуск на рабочий сервер не входит в локальную проверку и не будет заявлен без отдельного подтверждения.

Существующие незакоммиченные изменения сохраняются. Секреты не выводятся и не копируются в отчёты. Тестовые аккаунты и данные отделены от рабочих. Интерфейс не выдумывает пользователей, онлайн-статус и готовность приложений.

## 1. Люди и сообщества — сдано локально

1. Сохранённый профиль: имя, описание, темы, явная видимость в каталоге. По умолчанию приватность; свои группы доступны независимо от публичности.
2. Сообщество: публичная витрина, правила, открытое вступление / заявка / приглашение; роли участника, модератора и владельца.
3. Раздельные полномочия: вступление не добавляет контакт и не даёт управление компьютером. Участники читают чат, посторонние видят только разрешённую витрину.
4. Выход, удаление участника, блокировка, передача владения и архивирование. Действующие права перепроверяются сервером.
5. Чат с ограниченной выдачей, повторяемой отправкой без дублей и сохранением истории. Понятные состояния загрузки, отказа и отсутствия данных.

- [x] Миграции и постоянное SQLite-хранилище.
- [x] API проверяет подписанную личность, права и повторные запросы.
- [x] Отдельные пользователи: создание → вступление → сообщение → удаление → отказ в доступе.
- [x] Скрытый профиль отсутствует в публичном поиске людей и его счётчике; доступ к сведениям участника группы проверяется отдельно.
- [x] Пользовательские сценарии в браузере, включая заявку и действия владельца.

## 2. Общий мир — сдано локально

1. Поиск людей и сообществ с ограниченной выдачей и переходом по страницам; только разрешённые публичные данные.
2. Два равноправных представления: доступный список и поле сот с устойчивыми островами сообществ.
3. Переход из острова в витрину и далее к вступлению/чату. Приватные группы, скрытые люди и офлайн-состояние не подменяются декоративными данными.
4. Удобное управление мышью, касанием и клавиатурой; восстановление положения/вида без поломки навигации.

- [x] Поиск и фильтры работают с реальным API.
- [x] Публичный просмотр не раскрывает закрытый чат и приватных участников.
- [x] Поле, список, профиль и сообщество работают на 390 и 1440 px.
- [x] Браузерный сценарий: найти → посмотреть → вступить → общаться; скрыть себя → исчезнуть из каталога другого пользователя.

## 3. Приложения с устройств — сдано локально

1. Подтверждённая локальным коннектором привязка компьютера к аккаунту: общего Link ID недостаточно.
2. Постоянный реестр приложения: имя, устройство, явный loopback-порт, стартовая страница, доступ конкретным людям/группам.
3. Исходящий удостоверенный канал коннектора; HTTP и WebSocket через ограниченные потоки с отменой и обратным давлением.
4. Изолированный origin приложения, одноразовый запуск и отдельная сессия; ключи Сот не попадают в приложение.
5. Правдивые состояния: доступно, сервис остановлен, устройство отключено, доступ отозван. Отзыв закрывает уже открытые потоки.

- [x] Настоящее локальное приложение со статикой, формой/API и WebSocket открывается через шлюз.
- [x] Второй участник группы получает доступ; посторонний — отказ.
- [x] Удаление из группы и отзыв приложения закрывают старые сессии.
- [x] Остановка сервиса и коннектора различается; после перезапуска реестр сохраняется.
- [x] В браузере проверены iframe, загрузка ресурсов и cookies на изолированном origin.

## 4. Создание с агентом — сдано локально; внешняя модель требует конфигурации

1. Явный запрос создать приложение на выбранном доверенном устройстве. По умолчанию коннектор создаёт отдельную папку `Soty Apps/<jobId>` внутри разрешённого workspace; явный полный путь доступен в дополнительных настройках.
2. OpenCode сохраняет строгий `.soty/app.json`; коннектор проверяет схему, путь, ограничения и доступность порта.
3. Результат появляется как предложение приложения. Добавление использует реестр этапа 3, без отдельной системы публикации и автоматической выдачи групповых прав.
4. Ошибка агента, неверный manifest, выход за разрешённую папку или незапущенный проект показываются честно и не создают готовую соту.

- [x] Durable job сохраняет проверенное предложение приложения.
- [x] UI позволяет создать → увидеть результат → добавить → открыть → дать доступ группе.
- [x] Проверены опасные/ошибочные manifest и повторная обработка результата.
- [x] Реальный вызов внешней LLM отдельно отмечен в отчёте: транспортные тесты не выдаются за выполненную платную генерацию.

## 5. Итоговый интерфейс и качество — сдано локально

1. Утверждённая композиция: светлое поле, графитовая шапка, медовый акцент, острова сообществ, боковая панель; на телефоне нижняя навигация и удобные листы.
2. Пять полноценных состояний: мир, поиск/человек, витрина группы, совместная работа, мои соты/видимость.
3. Короткие подписи только там, где они помогают выбрать действие. Узнаваемые кнопки, явное состояние выбора, корректные пустые/ошибочные состояния.
4. Анимации отражают причинно-следственную связь, поддерживают reduced motion и не задерживают действие.
5. Личная настройка представления; клавиатурный фокус, доступные названия и удобные зоны касания.

## Журнал приёмки

Записи добавляются после проверок. Флажки выше подтверждают конкретные проверки; этап целиком сдаётся после интегрированного пользовательского сценария.

- Основа: исходные 60 тестов Connect и проверка TypeScript прошли. Исходная сборка: JS 545,70 КБ / gzip 178,32 КБ, CSS 49,46 КБ / gzip 10,62 КБ. Новая точка входа вынесла прежние инструменты в отдельную загрузку. Итоговые размеры фиксируются после последней сборки.
- Сообщества: 24 теста хранилища, миграции, приватности, ролей, чата, аватаров и настоящего подписанного HTTP. Две отдельные браузерные личности: скрытый профиль, поиск публичной группы, витрина без доступа к чату, заявка, принятие владельцем, обмен сообщениями — проверено. Устаревшее состояние ожидающей заявки исправлено обновлением видимого экрана, автоматический переход после одобрения проверен.
- Приложения: 11 тестов, в том числе запуск полного `scripts/soty-connector.mjs` и настоящего HTTP/WebSocket приложения. В отдельной браузерной приёмке проверены одноразовый запуск, изоляция origin, общий доступ двух участников, отказ постороннему, отзыв уже открытого соединения. В основной оболочке владелец подключил тестовый компьютер и добавил приложение «Покупки» с доступом «Мастерской».
- Агент: подписанные задания привязаны одновременно к аккаунту, устройству и коннектору; общий прежний Link ID не позволяет прочитать или отменить их. Manifest, разрешённый путь, свежесть результата и действующий порт проверяются до предложения добавить приложение. Это ещё не доказательство выполненного запроса внешней LLM.
- Полная оболочка: два независимых аккаунта «Алексей · тест» и «Маша · тест» обменялись сообщениями; Маша открыла опубликованные «Покупки» и добавила «Фрукты». После явного удаления владельцем открытый WebSocket закрылся, элементы приложения перестали принимать изменения, новый запуск показал «Доступ к приложению закрыт». Повторная заявка и принятие автоматически открыли чат на ожидающем экране без перезагрузки.
- Навигация: прямой URL сообщества, Back между вкладками, переход в прежние комнаты и обратно проверены в браузере. Старое пространство открывается отдельной ленивой частью; учётная запись остаётся общей.
- Настоящий OpenCode: установленный CLI 1.18.15 выполнял отдельный account-owned job через настоящий runtime и локальный контролируемый inference-сервер. Задержка 2300 мс пересекла два цикла опроса отмены; CLI вызвал настоящий write tool и записал свежий manifest в автоматически созданную папку. Коннектор вернул проверенный appProposal, затем прошли регистрация и launch. Это подтверждает исполнение CLI и протокол, но не качество или доступность рабочей внешней модели.
- Финальная регрессия: Connect 64/64; `world:test` 51/51, включая World, Apps, server, реальный CLI, avatar codec и восстановление регистрации коннектора, без пропусков; fullstack dev 2/2. Всего 117 тестов. TypeScript, identity, traffic, connector release/update/store/model proxy и runtime integration — PASS.
- Исправлены обнаруженные при приёмке дефекты: обрезанный остров поля, устаревшая заявка, потеря контекста Back, ICC metadata аватара, одноразовый ticket при внешнем открытии, cookie iframe, ложная отмена account-owned job, лимит JSON большого ответа агента, повторная передача всей истории в runtime ACK и отсутствующий CSS proxy chunk в SW.
- Видимость: в браузере второго аккаунта поиск «Алексей» сначала вернул один профиль. Владелец выключил видимость через настройки; новый поиск «Алексей · тест» вернул «Пока никого не нашли» и нулевой счётчик. После проверки настройка возвращена для локального показа.
- Создание с ИИ через UI: отдельный временный стенд 5310, настоящий коннектор 49430 и установленный OpenCode. Через кнопки выполнены подключение устройства → описание → создание без ручного пути → проверенное предложение → добавление → открытие → изменение списка в iframe → доступ тестовой группе → приложение в её вкладке. Ошибок консоли нет. Ответ inference локальный и контролируемый, HTTP-приложение заранее запущено стендом; это приёмка механизма, а не качества генерации внешней LLM. Стенд после проверки остановлен; три снимка сохранены.
- Итоговая визуальная приёмка: пять пар настоящих экранов 1440×900 / 390×844, дополнительно 768 px. Измерено отсутствие горизонтального переполнения страницы, зацикливание фокуса и возврат после Escape. Исправлено пересечение мобильной кнопки с навигацией на 1,59 px; теперь между ними 8 px. Пользовательский reduced motion дал вычисленную длительность 0s. Временный viewport сброшен.
- Итог сборки: обязательные JS + CSS нового пространства 187 276 байт / 54 454 байта gzip, приблизительно на 71% меньше исходной загрузки. Все 13 файлов precache существуют. Коннектор 1.3.0, проверены целостность выпуска и обновление с 1.2.0. Локальный preview отвечает 200, отдельный тестовый inference-стенд остановлен.

## Итог и границы сдачи

Все пять этапов реализованы и приняты на изолированных локальных данных. Подробности, десять снимков и воспроизводимые проверки: [отчёт приёмки](../research/world-acceptance-20260928.md). Исследования и визуальные измерения связаны из этого отчёта.

Рабочий запуск требует отдельного домена приложений с DNS/TLS и серверной конфигурации inference. Внешняя модель, публичная нагрузка, физические телефоны и браузеры вне проверенного Chromium не выдаются за проверенные. Попиксельное совпадение с художественными рендерами не заявляется; реализованы их композиции с настоящими данными и действиями.
