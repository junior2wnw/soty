# Метки · NFC

Отдельное приложение Сот: https://nfc.соты.online. Источник работает на SSH dev, локальный порт 5318; наружу приложение открывает коннектор и Soty gateway.

Подготовка ссылки, текста, vCard-контакта, Wi-Fi WSC, телефона, письма, SMS, координат, JSON и MIME/HEX. До 16 записей на метку; локальные шаблоны, импорт/экспорт JSON, передача подготовленного содержимого по QR-фрагменту. Сервер не получает содержимое меток.

Чтение и запись используют настоящий Web NFC в Chrome на Android. На iPhone и компьютере доступна подготовка. Нужны HTTPS, верхнее окно, включённый NFC и разблокированный экран. Перезапись прежнего содержимого требует отдельного флажка. Запись проверяется повторным чтением; непроверенная запись получает отдельный результат. Закрытие записи навсегда требует ввода подтверждения и зависит от поддержки телефона и метки. Сырое чтение памяти чипа, пароли секторов, эмуляция карт и запись платёжных карт не поддерживаются.

Локальная разработка: npm ci, npm test, npm run dev. Сборка: npm run build; npm start обслуживает dist на 127.0.0.1:5318. Dockerfile собирает и тестирует приложение на закреплённом Node 24. Контейнер публикует порт только на loopback хоста.

Инструкции общей публикации: [поддомены приложений](../../docs/deployment/app-subdomains.md). Физический NFC нужно проверять на настоящем Android с метками; программные проверки жизненного цикла этого не заменяют.

Главный сценарий: выбрать тип → заполнить → записать. «Считать» и «Мои» в нижней навигации. Меню «…» содержит сохранение, перенос на телефон, дополнительные записи и настройки перезаписи. При отсутствии Web NFC главное действие предлагает QR-перенос на Android; внутри iframe — отдельное окно. Запись доступна только по явному нажатию владельца телефона.

Приложение имеет свой PWA-манифест. NFC не требует отправки содержимого на сервер: уже открытый интерфейс может работать без сети. Для нового открытия нужна сеть. Шлюз Сот сейчас запрещает service workers у приложений; отдельный офлайн-кеш потребует собственного проверенного профиля размещения.

Для агентов доступен `/agent.json` с типами и форматом обмена. Агент создаёт JSON-файл со schema `soty.nfc-template.v1`, name и records; все значения полей — строки. Пользователь открывает файл через меню и подтверждает замену черновика. Пример:

```json
{"schema":"soty.nfc-template.v1","name":"Соты","records":[{"kind":"url","values":{"url":"https://соты.online"}}]}
```

Операции с физической меткой выполняет телефон с разрешением Web NFC. Удалённого API записи чипов нет. Не помещайте настоящие пароли и личные данные в публичные примеры или QR-ссылки.
