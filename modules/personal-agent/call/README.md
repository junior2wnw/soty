# Neutral call lifecycle — P2.3 source component

V3 after independent Astra reentrancy/track-adoption HOLD; author tested, independent retake pending. V1 capacity HOLD and V2 peer HOLD remain unchanged in their original folders. This is a small browser-compatible ES module and synthetic test kit, not a live call, UI, transport adapter or authorization implementation. No dependencies, Node/DOM/permission/network access in runtime. Host decides where to keep the instance so same-account navigation does not destroy it.

## User behavior and API

`createCallLifecycle({host, media, transport, onState?})` returns a single local session owner. First call `setIdentity({accountId, deviceId})`; null logs out locally. Values are copied. `join({roomId, mode: 'one-to-one' | 'group'})` authorizes and joins receive-only. State becomes `listening`, microphone remains `off`, no capture is requested. Repeated same-session intent returns the same join promise. Different room/mode is rejected `call_active`; explicit end is required before replacement.

`enableMicrophone()` is a separate explicit user intent. It authorizes publication, acquires audio-only capture, disables ALL acquired tracks before giving them to a publisher, stages publication, awaits commit, rechecks identity/generation/current mic intent and then enables tracks. Repeated pending/on intent does not duplicate capture. UI adapters must wire this method only to a deliberate user action, not page mount or join completion. This headless component cannot prove physical user activation.

`mute()` invalidates the mic intent, stops every known local track and disposes the publication. It does not only flip `enabled`: next enable gets a fresh stream. `end()`, `cancel()`, `revoke()`, changed account/device, null identity and `dispose()` cancel the call and stop its local tracks. Native track `ended` events stop the whole local capture and publication; no auto-unmute. `navigate()` is a no-op snapshot, and repeated same account/device does not end a call. Host must not call dispose on an ordinary route change.

`snapshot()` returns frozen state/scope/evidence with no tokens, error details, SDP, transcripts or device labels. State: idle, joining, listening, ended, disposed. Mic: off, permission (includes admission wait), publishing, on. Failures use fixed codes. `onState` is best-effort, microtask-coalesced; throwing observers cannot change operation results. It is not an event audit log.

Agent invitation, recording and transcript are three separate unintegrated features. `requestExtra('agent-invite' | 'recording' | 'transcript')` returns `feature_not_integrated` and performs no IO. Join/mic never implicitly request them. A future UI must expose separate explicit choices and a future adapter must implement their authority, consent and teardown. No flag is reported as recording/agent/transcription active. Human transport, audio gateway/provider and agent/GLM reasoning are separate extension boundaries; no provider or brain is imported.

## Trusted port contract — not signed authority

The instance is created by a trusted host. All callbacks are trusted resource adapters, not data obtained from arbitrary messages. Ordinary room descriptors, membership booleans or an object shape are NOT signed authority.

- `host.authorize(scope, 'join' | 'microphone', {signal}) -> opaqueAdmission`: the trusted adapter must perform actual current authorization and obtain any required signed/token-bound admission. The component rejects primitive/boolean results, but accepting an opaque object/function says nothing about its authenticity. It forwards this object only to the corresponding trusted transport stage. It never exports/persists it. Host must call revoke on authority loss. Server-side continuously enforced membership/revocation is mandatory for integration.
- `transport.join({scope, admission, signal}) -> session`: receive-only, no implicit media, recording or agent. Session implements `close()` and `preparePublication(...)`. Abort must retire external work; a late resolved session is closed by the component. One current logical local call does not prove only one remote/SFU session exists during a non-cooperative late join.
- `media.acquire({audio:true, video:false, scope, signal}) -> nativeLikeStream`: exclusive ownership of a stable `getTracks()` array; every track has native MediaStreamTrack semantics. No hidden/cloned capture resources outside this array. Real getUserMedia may ignore abort; late streams are adopted and all tracks stopped. An invalid adapter whose getTracks throws/hides tracks cannot be cleaned up by this module. Adapter is responsible for resources it fails to return.
- `session.preparePublication({scope, tracks, admission, signal}) -> stage`: tracks are disabled. Must not enable tracks, clone live capture, replace them or transmit source PCM via an independent path. Stage has `commit({signal})` and idempotent `dispose()`. Commit must await real publication admission; dispose/abort must tombstone the stage so a delayed commit cannot reattach after disposal. Tracks stay disabled until commit resolves and local generation checks pass. Late stage results are disposed. This contract is tested at mock ports, not proven for an SFU/provider.
- Session close/stage dispose may return promises. Local stop never awaits them. Rejections increment bounded numeric evidence and are not exposed verbatim. Disposable objects must have distinct identity per owned resource. Track enabled/stop/readyState and event methods must follow native synchronous semantics.

Scope is a frozen value `{accountId,deviceId,roomId,mode,generation}`. Every join gets a new generation. Async continuation also checks exact call/mic object identity, so A→B→A or mute→enable cannot revive a retired operation. Public pending intent promises settle with `stale` promptly on cancellation; resource work may still finish later and has attached cleanup handlers. There is no timer-based retry or hidden reconnect.

V3 establishes a synchronous teardown barrier before abort/stop/close/dispose callbacks. Identity is installed before retiring its old call; permanent closed is set before disposal. Join/mic/setIdentity reentry during cleanup returns `call_transition` (join on disposed returns `disposed`) without allocating work. Resource method getters are read into local handles; current-generation checks follow each getter before starting further resource IO or committing listening/on state. Actual invocation uses Reflect.apply for cached handles. Cleanup remains callable and keeps the barrier through callbacks; this does not defer stopping tracks.

Returned track Arrays are inspected via own indexed data descriptors, not Symbol.iterator/index getters. Every safely discovered track is retained before shape rejection. Missing indices, accessors, unknown properties or descriptor failures are rejected; safely discovered tracks are stopped, and unknown ownership quarantines its slot. One failing descriptor does not prevent inspection/cleanup of later known indices. Malicious hidden resources or traps that entirely hide keys remain outside observable cleanup, but never justify claiming a freed capture slot.

## What local stopping proves

End/mute returns a point-in-time snapshot. `observedLocalTracks`, `stopCallsReturned`, `endedLocallyObserved`, failures and pending resource/disposal counts are separate. `stopCallsReturned` means only that the local method returned. `endedLocallyObserved` requires reading readyState=ended after stop. A throwing stop is reported as failure; other tracks are still stopped. Pending permission can be visible in evidence, and its later tracks are stopped when delivered. Snapshots are immutable observations, not promises that no future result exists. After a new call starts, snapshot describes that call, not an unbounded history of retired calls.

`remoteTerminationVerified` is always false. No remote device stop, capture LED timing, revocation acknowledgement, erase, recording deletion, E2EE or acoustic privacy guarantee is made. Browser permission may start local capture BEFORE the resolved stream reaches JS; the first action after adopting all tracks is disabling them. No publication occurs before local disabled state under the trusted adapter contract. Immediate hardware shutdown while a browser permission dialog is unresolved cannot be guaranteed.

No deadlines are imposed on trusted provider work here. Cancel makes local state terminal promptly and fences late results; an adapter that never settles retains its occupied slot indefinitely. Mandatory adapter deadlines AND transport lease expiry remain integration requirements, including page/process suspension and browser-native revocation. A timer firing alone must not pretend an actually live operation/resource settled. SFU/TURN/Connect membership, paid gateway and real browser tests are separate integration gates.

## Hard total ownership capacity across generations

There are16 total fixed ownership slots, across current and retired operations. A call slot covers authorization, joining, live session and its close; a mic slot covers authorization, capture, staged publication/commit, track ownership and disposal. Each can own one resource group (not one scalar JS object); a valid capture group has at most8 tracks. Thus there is no unbounded queue of retired jobs or resources. Pending work and pending disposal can coexist within the same occupied slot and neither releases it prematurely. The limit is16 ownership groups, not a claim of at most16 individual track/session objects.

A new join or mic intent reserves a slot BEFORE any port call. No slot yields `call_capacity` with no authorization/acquire/join call. Repeated same intent coalesces before capacity admission. End, cancel, mute, identity change, timeout assumptions and UI generation changes do not free a slot. Only actual work settlement plus retirement plus all disposal settlement and observed local track endings do. Failed/uninspectable cleanup conservatively quarantines the slot; there is no force-clear or automatic retry. Slots may intentionally stay exhausted until the trusted adapters/host resolve the underlying fault.

Over-limit/mixed unexpected streams are rejected and every returned track is stopped, including tracks beyond the limit. A native-like adapter can temporarily return a malformed oversized array; the component cannot prevent that caller-owned allocation, but retains no successful publication from it. Its late tracks are also cleaned. Track counters use WeakMap identity and numeric totals, not a growing strong history. The capacity Set retains at most16 small ownership records; last ended call is at most one snapshot context. Notifications have at most one queued microtask. User-held returned promises/snapshots and arbitrarily allocating hostile adapters remain outside this ownership bound.
