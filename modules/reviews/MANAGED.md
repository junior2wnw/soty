# Optional managed Povédai Source port

`server/managed-port.mjs` is a trusted asynchronous composition port alongside the unchanged public-read1.1 service. It has no default HTTP/MCP binding and no Root database. The author supplies only an existing app, typed local subject and bounded data; registry, owner/tenant, environment, provider pins, credentials and Source grants are host/Source authority.

The Root host supplies exact reviewed `providerRef`, actual Source code port, private `resolveSourceCredential`, **`withRootActorAuthority(originalActor, callbackVerifiedOwner)`** and actual `withAppAuthority`. Field-based `actorActive` alone cannot instantiate this managed port. The proof wrapper keeps the original branded Connect/capability object; only inside its current synchronous authority fence does it deliver the closed `{accountId, deviceId}` metadata used by Apps. Never clone a proof object or claim that a capability credential is a signed Connect actor. Signed Connect composition uses `connect.withActorAuthorityFence(original, () => callbackVerifiedOwner(original))`. Capability composition uses `connect.withAuthorityFence(() => caps.withOwnerAuthority({actor: original}, callbackVerifiedOwner))`. These are separate proof families, and neither wrapper grants Human identity or Source tenant rights.

Both host fences remain synchronous; Source work happens outside the Apps/Connect/SQLite fence. Current app/owner/account/device/target/policy and Root authority are checked before credential resolution, after credential resolution and after Source work. Skipped, repeated, late/swallowed duplicate or async authority callbacks cannot acknowledge readiness. Source actor callbacks are also single-entry and cannot dispatch after their lifetime. Per-process outstanding Source work is limited to four actual promises, retained after timeout/ignored abort; no private-content cache or automatic retry exists. A Source commit followed by a lost ACK remains an unknown outcome until explicit current-authority reconciliation; a timeout does not imply that the native effect was cancelled.

`list` obtains current native placement context and the native list under the same Source actor, outside Root fences, and binds every item's object/subject to that placement. `managed-projection.mjs` closes every nested native review/author/tag DTO. Known native `publicReview` redactions may be enumerable `undefined` only in-process and are omitted. Unknown fields, nonempty private metadata, email/identity claims, accessors and foreign placements fail502 without returning any item. Native body/reply fields remain data; the renderer must escape content and load asset URLs without Root credentials. This projection neither sanitizes arbitrary HTML into executable code nor certifies Source code or moderation policy.

Operations `provision/context/list/collect/publish/moderate` validate arguments before Source dispatch. Managed API/DTO uses `povedai.managed-reviews.v1`. `provision/context/publish` return a verified Source tuple with a host-scoped subjectRef and providerRef. These hashes bind resource semantics; they attest neither release code nor Source operational readiness. Source grants approve actual native rights. They are not generated from Root author drafts, native profiles, titles, metadata or agent OAuth.

The separate reviewed Source checkout at `output/povedai-managed-source/worktree` is based on4cb52f and contains JSON2 native/managed atomic storage, independent literal reader2, additive native account links, private placement provisioning and actual HTTP routes (default503). Its `docs/managed-reviews-v1.md` specifies reader-first rollout/fallback, limits and unsupported production Source RP/PG/transport/adoption/UI/agent-budget paths. The Source commit/change packet must accompany this Root slice; an ignored working copy alone is not a release artifact. Original `D:/отзывы` remains unchanged.

The real synthetic Root+Source test must run from the Source checkout with its existing tsx dependency: `node --import tsx --test <Root checkout>/modules/reviews/fixtures/managed-source-http.test.mjs`. It uses real signed Root Human/Apps authority, maintained JOSE/userinfo, native Source JSON/HTTP and finite Source grants; no production tokens/configuration/users or public writes occur.
