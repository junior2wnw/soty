# Ordinary Source3: отдельная физическая холодная проверка

Это **Native persistence/crypto/custody** acceptance, не login и не permission. Фиксированная fixture создаёт только synthetic Source Native rows: выбранный ресурс,owner/reporter роли,2 Native session hashes, PNG ticket+original receipt и AES-GCM/AAD checkpoint. RP/Root sessions/tokens/issuer proof не подделываются; `authenticationProved:false`, `productionReady:false`. Выключенные models/jobs/Long не становятся Ready после cold restore.

Все Docker действия выполняет отдельный Root-operator serial runner. Private operator input — measured Source image id/revision/packet hash, exact own socket/CLI, reviewable fixture+manifest pins, свежий random nonce и protected lab. Из авторского JSON эти значения не принимаются. Физически нужны **два новых named volumes**; tmpfs/обычный temp-directory не засчитываются.

`cold-guardian.mjs` и `runner.mjs` требуют trusted Linux **Node24/UID1000**. WSL host Node18 не допускается: shared restore profile опирается на native Node24 stream behavior. Guardian проверяет exact packet/CLI/socket pins; runner принимает только5 закрытых operator fields. До запуска оператор подготавливает два свежих volume c exact nonce labels и root UID1000/mode700. Source child не получает Docker socket; он доступен только trusted Node24 supervisor. Этот supervisor/preSTART admission и весь packet должны быть отдельно рассмотрены перед RUN. В текущем draft нет автоматического unreviewed Docker создания supervisor или volumes.

Новая отдельная `cold-supervisor.mjs` — Node18 HOST launcher фиксированного Node24 образа8fd/UID1000; проверяет полный выбранный spec, exact private image env/workdir/tmpfs и ровно4 binds: private lab-parent stubRO, только packetRW, verified CLIRO и socketRO/GID1001. Rootlab целиком не раскрывается; Source helpers получают только packetRO+own physical volume, без socket. Immutable profile2 сохраняет Source407/e8d/ff7b; current profile3 фиксирует отдельно измеренный key-probe Sourceffce/B589/bbe22. Новые bytes требуют нового immutable profile/pins, старые не переписываются. `operator.template.json` намеренно не принимается с placeholderCLIsha. Все Source/volume bootstrap/вызовы — только explicit Root reviewed RUN.

Перед CREATE в private parent stub создаётся ровно один пустой public `source-cold-<exactnonce>` target для вложенного packet bind. Это не расширяет LAB access. В compile-only cold bundles `__SOTY_SOURCE_COLD_BUNDLE__=true` подавляет только auto-CLI `backup.mjs`, который иначе ошибочно считает общий bundle своим прямым entry; standalone production backup CLI и encryption logic сохраняются. Перед cleanup supervisor проецирует только closed State/State.Error/CLI exit classes; raw Docker error/stderr/env в public receipt не попадают. Новый packet не запускает/не удаляет прежние failed attempts.

1. Read-only inspect exact Source image и `assertInstalledSourceImage` до любого Source START. Root storage/universal labels не допускаются. Подготовить current/compatible Source Reader3 image и literal Reader2-refusal baseline. На собственном новом physical volume создать полный `/data` UID1000/GID1000/mode700 fixed scaffold. Ни serving container, ни старый residue не монтировать.
2. Запустить один собственный Source-image container с fixed `/probe/fixture.mjs seed`, readonly rootfs/noNetwork/noCaps/noNewPriv,UID1000,≤256MiB/pids64,bounded `/tmp`, одним RW named `/data` и RO public packet; без socket/секретов Root. Fresh independent preSTART spec, image/argv/mount identity и exited0 обязательны. После stopped проверить other RW writers=0, literalReader3/Reader2 refusal/FK и закрытые Source counts.
3. Сохранить **private** witness и coherent inventory/Source config/key bytes. `fixture.mjs witness` содержит private file hashes для strict restore inventory: их не выводить в tool/report; наружу только equality/counts. Строить source witness `{generationId,checkpointSha256,inventorySha256}` и `soty.restore-manifest.v1` с отдельным `ordinary-native` store и всеми `/data/native`+`/data/install` files. Отдельный host-only `createOrdinaryNativeRestorePorts({realmId:'cold-synthetic'})` использует fixed Native3/store/path `native/native.sqlite`, actual prearchive Reader3 checkpoint29/realm и повторный independent reader после restore; checkpoint metadata само не authority. Root/R0 ports сохраняют прежний required `connector-store.sqlite` и missing-Connect deny. Existing `deploy/connect/backup.mjs encryptBackup` и `backup-format/restore-backup/restore-sink` сохраняют RSA3072-OAEP-SHA256/AES-GCM, strict authenticated inventory,tar path/byte bounds и no Symlink/partial target. Не создаётся другой crypto/tar/auth протокол.
4. Archive только после Source stopped/no other writers и SQL checkpoint/close. Actual full guarded stopped seed original (ID/image/State timestamps/RestartCount/mount/config) проверяется до/после; выбранный actual original хранится только внутри encrypted metadata, без подставленного `Running:false`. Private metadata в encrypted envelope; plaintext config/key/tar не сохранять на host. Для strict sink второй fresh physical named volume предоставляет отдельный private namespace/data/config mount witness, реальный `/proc/self/fdinfo` mountId+dev/ino и untouched empty roots.
5. Independent authenticated dry inspect **до** extraction, затем existing strict sink/readOnly sender. На втором named volume сравнить private Native bytes/config/key equality, Native IDs/roles/PNG/original receipt/cipher digest,FKs и2 independent reader. Reader2 должен отказать **доSTART**. После cold Source stillneeds actual current Root/Human/Native login; никакой resurrect Basic. Source CLI `reader` с отсутствующим/неверным key/config/foreign realm должен отказать; image label alone не admission.
6. Guarded compatible Source-image START на втором physical volume с настоящим installer entry и no actual Root connector: listener жив, а unsigned/spoofed Root/Native read denied. Это не remote browser/TLS/Root ready acceptance. Осмотреть stopped/noOOM/exit/every owned container+volumes cleanup и публиковать только chosen DTO. Unknown cleanup — сохранить owned evidence,fail,не удалять неопределённый reachable target и не rerun mutation.

Публичный prepare script берёт exact canonical Git bytes. Source4/Long writers не импортируются. После успешного RUN отдельный immutable receipt должен перечислить Source/fixture/image/parentOCI/reader/restore pins и физические volume ids. Пока RUN не выполнен, исходный packet/план не считается cold PASS.
