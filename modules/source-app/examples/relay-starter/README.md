# Новый проект: общий вход Сот

Шаблон использует `createRelayIdentityFetch` и `createRelayPersonalServer`.
Вход только из текущего встроенного окна Сот. Своих паролей, cookies входа,
отдельной регистрации и перехода в Native-вкладку нет.

1. Проверь опубликованный SDK, SHA и поддерживаемый контракт на вашем Root.
   Установи пакет в `.soty-sdk` в корне проекта вместе с lockfile dependencies.
2. Зарегистрируй `.soty/app.json` через существующий коннектор владельца.
   Выполни signed `apps.authentication.get({appId,expectedAccountId})`.
   `supported:true` — только совместимость платформы/коннектора, не готовность приложения.
3. Запиши выданный appId и доверенный issuer в `.soty/app-auth.json`.
   Не бери issuer из query, тела запроса, email или произвольного родителя.
4. Для новой пустой базы запусти `node app/server.mjs --initialize`.
   При последующих запусках: `node app/server.mjs`. Базы в `data` сохраняй.
5. Открой карточку внутри Сот. Добавь запись, перезагрузи окно и проверь readback.
   Повтори с другим человеком и после смены профиля и отзыва доступа.

Личные данные разделяются по проверенным issuer/subject в одной транзакции с
квитанцией. Существующая база не мигрируется. Для команд используй
`createAppAccess` и свои ресурсы: права Сот/карточки не дают роль в чужой команде.
Старые аккаунты связываются только при доказательстве владения обеими личностями,
никогда по совпавшему email. Подробности и сценарии: `/agents/shared-auth.md`.
